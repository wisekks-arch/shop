# 🛍️ 이지샵 (EASYSHOP) - 모던 E-커머스 쇼핑몰 플랫폼

이지샵(EasyShop)은 고객이 다양한 카테고리의 트렌디한 상품을 편리하게 탐색하고, 장바구니/옵션 관리, 쿠폰 적용, 결제 및 배송 조회를 수행할 수 있으며 관리자가 매출 통계, 상품 CRUD, 주문/배송 처리 및 Q&A를 통합 관리할 수 있는 풀스택 E-커머스 웹 애플리케이션입니다.

---

## 🌟 주요 기능 명세

### 1. 🛒 사용자 쇼핑몰 화면 (Customer Frontend)
- **메인 홈 (`/index.html`)**:
  - 히어로 프로모션 배너 및 신상품 바로가기
  - 카테고리 탭 네비게이션 (패션, 디지털, 뷰티, 리빙, 푸드)
  - 타임세일 위젯 (실시간 카운트다운 타이머 및 한정특가 상품)
  - 베스트셀러 상품 랭킹 및 실시간 고객 리뷰
  - 4대 고객 안심 서비스 (100% 정품, 빠른 배송, 무료 반품, 24시 고객센터)
- **상품 탐색 & 필터 (`/products.html`)**:
  - 다중 카테고리 및 가격대 (5만원 이하 ~ 15만원 이상) 필터링
  - 무료배송, 세일, 베스트셀러 조건 필터
  - 추천순, 판매인기순, 낮은/높은 가격순, 평점순, 리뷰순 정렬
- **상품 상세 페이지 (`/product-detail.html?id=...`)**:
  - 고화질 갤러리 썸네일 뷰어
  - 옵션 선택기 (색상/사이즈) 및 수량에 따른 실시간 총 결제금액 산출
  - 찜하기(위시리스트), 장바구니 담기(드로어 연동), 바로구매
  - 탭 메뉴: 상세정보, 스펙 고시정보, 구매후기 작성/조회, 상품 Q&A
- **장바구니 (`/cart.html` & 사이드 드로어)**:
  - 상품 개별/전체 선택, 수량 변경 및 실시간 금액 계산
  - 50,000원 이상 무료배송 자동 게이지
  - 할인 쿠폰 코드 (`WELCOME10` - 10% 할인, `EASY2026` - 5,000원 할인)
- **주문서 작성 & 결제 (`/checkout.html` / `/order-complete.html`)**:
  - 배송지 정보 입력 및 결제 수단 선택 (신용카드, 카카오페이, 토스페이, 가상계좌)
  - 주문 접수 시 주문번호(`ORD-YYYYMMDD-XXXX`) 자동 발급 및 접수증 확인
- **주문 / 배송 실시간 조회 (`/order-lookup.html`)**:
  - 주문번호 + 연락처 검색으로 결제완료 -> 상품준비중 -> 배송중 -> 배송완료 타임라인 확인

### 2. 📊 관리자 어드민 대시보드 (`/admin.html`)
- **통합 KPI 대시보드**: 당일 매출, 당월 누적 매출, 미처리 신규 주문, 품절 임박 상품 현황 및 7일간 매출 추이 차트
- **상품 관리 (CRUD)**: 신규 상품 등록 모달, 상품 정보 수정, 삭제, 재고 및 판매상태 관리
- **주문 및 배송 관리**: 주문 내역 조회, 주문 상태 변경, 운송장 번호 등록
- **고객 문의 관리**: 1:1 문의 및 상품 질문 열람, 관리자 답변 등록 및 상태 갱신

## 🚀 실행 및 배포 주소

- **로컬 실행**:
  1. `start.bat` 파일을 더블 클릭하여 실행하거나,
  2. PowerShell에서 아래 명령어를 실행:
  ```powershell
  powershell -ExecutionPolicy Bypass -File server.ps1
  ```
- **로컬 접속 주소**:
  - 사용자 쇼핑몰: `http://localhost:4000`
  - 관리자 어드민: `http://localhost:4000/admin.html`
- **GitHub Pages 실서버 배포 주소**:
  - 쇼핑몰 메인: https://wisekks-arch.github.io/shop/index.html
